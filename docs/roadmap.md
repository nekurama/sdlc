The implementation backlog is tracked in the [Bulb repository](https://github.com/nekurama/Bulb/issues/6). This repository holds the durable guidelines and setup documentation; implementation work remains tracked and reviewed in its work items.

## Suggested sequence

1. Freeze lifecycle and authorization contract (#7).
2. Define GitHub schema and templates (#8).
3. Prove local Paperclip behavior (#9).
4. Build sync and authorization controls (#10, #11).
5. Version policies and skills (#12).
6. Run the end-to-end pilot (#13).

The roadmap is guidance; update it when the canonical backlog changes.
